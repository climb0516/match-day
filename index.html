怎么订阅
iPhone：点「订阅」会直接打开系统日历；也可以复制链接，到 设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历，粘贴链接。
安卓 / 电脑：复制链接，在 Google 日历「其他日历 → 通过网址添加」，或 Outlook「添加日历 → 从 Internet 订阅」。
订阅后比赛自动出现在日历里，开赛前 30 分钟提醒；赛程每 2 小时更新一次，日历 App 会定期同步（各家频率不同，通常几小时一次）。
只想记某一场：在赛程里点那场右侧的 📅，下载单场日历文件。

我的关注

点比赛里的队名 / 选手名即可关注或取消，关注的比赛会高亮；只保存在本机浏览器。

数据来源

足球 / 篮球 / 综合：直播吧（ESPN 兜底）；电竞：Liquipedia（CC BY-SA 3.0）。时间均为北京时间，「进行中」按开赛时间估算。
